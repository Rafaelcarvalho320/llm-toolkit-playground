Tire o JSON de uma resposta bagunçada

Você pede JSON e o modelo responde com texto em volta, vírgula sobrando, comentário ou corta no meio. O json.loads recusa tudo isso. O llm-json recupera o valor e diz exatamente o que precisou consertar, inclusive quando faltam campos.

Tire os dados pessoais antes de mandar ao modelo

CPF, CNPJ, cartão, telefone e e-mail são trocados por tokens antes do texto sair da sua aplicação, e voltam depois na resposta. Cada número é confirmado pelo dígito verificador: um número de pedido com 11 dígitos não é tratado como CPF.

Veja um streaming quebrar, e não quebrar

O fake-llm faz o papel do modelo: primeiro responde HTTP 429, depois manda a resposta em eventos SSE, picotados nos pontos que derrubam leitores ingênuos, inclusive no meio de um caractere acentuado. Os mesmos bytes passam por um leitor comum e pelo sse-reader.

Compare duas exportações e ache cada divergência

Cole dois CSVs, escolha a chave e os campos. O reconciliation-report normaliza antes de comparar, então 1.234,50 e 1234.5 são o mesmo valor e José e JOSE também. Sobra só o que é diferença de verdade.

Como fica no código 
from reconciler import CsvSource, Schema, as_markdown, reconcile

schema = Schema.build(
    key=["pedido"],
    compare=["cliente", "total"],
    normalizers={"cliente": "unaccented", "total": "money"},
    tolerances={"total": "0.01"},
)
result = reconcile(CsvSource("erp.csv"), CsvSource("loja.csv", delimiter=";"), schema)
print(as_markdown(result))

Como funciona

Python de verdade

Não é uma reimplementação em JavaScript. O Pyodide roda o CPython compilado para WebAssembly, e as bibliotecas são instaladas a partir dos mesmos commits que passam nos testes de cada repositório.

Sem servidor

A página é estática e fica no GitHub Pages. O processamento acontece no seu navegador; os textos e CSVs que você cola não são enviados para lugar nenhum.

Sem dependências

Só funciona porque as cinco bibliotecas usam apenas a biblioteca padrão do Python. Isso também as deixa fáceis de auditar e de colocar em qualquer projeto.
